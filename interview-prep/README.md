# 面试准备：项目文档目录说明

## 目录说明

- `00_项目总览.md`：用于整理项目背景、技术栈、核心业务和个人职责。
- `01_总面试题.md`：用于汇总项目整体相关的高频面试题。
- `02_深度追问题.md`：用于准备面试官对技术细节的连续追问。
- `03_未来可改进点.md`：用于整理项目优化方向和后续演进思路。
- `04_潜在问题提示.md`：用于标记面试中需要谨慎回答的问题。
- `05_面试表达模板.md`：用于沉淀项目介绍和技术表达模板。
- `modules/`：按业务模块和技术专题拆分复习内容，包括项目模块总览、购票主流程、余票库存、并发控制、订单、缓存性能、分布式、数据库、用户认证、工程异常处理。

## 使用建议

- 开场介绍先看 `00_项目总览.md` 和 `05_面试表达模板.md`。
- 高频问答先看 `01_总面试题.md` 和 `02_深度追问题.md`。
- 单点复习直接进入 `modules/` 下对应专题文件。
